# Retail MKT Hub

Diseño gráfico, CM, redes y equipo de Retail MKT en una sola app (PWA instalable).

- `index.html` — la app
- `manifest.webmanifest` — nombre, ícono y colores de la app instalada
- `sw.js` — service worker: abre aunque no haya internet
- `icon-*.png` / `apple-touch-icon.png` — íconos

Ver `LEEME.txt` para instalarla en celular/iPad. Es un sitio estático: se publica en Vercel
importando este repo (sin build, sin framework).
